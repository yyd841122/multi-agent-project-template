# Requirements Example

> 本示例来自 todo-agent-workflow-demo 项目的简化版本。
> 请根据实际项目需求修改此模板。

---

## 1. 项目说明

**项目名称**：[Your Project Name]

**项目类型**：Claude Code 多 Agent 协作开发验证项目

**项目目标**：
通过一个简单的业务项目，验证和演示 Claude Code 多 Agent 协作开发流程。

**重要说明**：
- 本项目的主要目标是验证协作流程，不是构建复杂业务功能
- 业务功能只是验证流程的载体
- 核心价值是积累多 Agent 协作经验和最佳实践

---

## 2. 用户目标

描述用户希望通过本项目解决什么问题。

**示例**（来自 Simple Task App）：
用户需要一个简单的任务管理工具，可以：
- 添加任务
- 标记任务完成
- 删除任务

---

## 3. 功能需求

### 3.1 核心功能

列出项目必须实现的核心功能。

**示例**（来自 Simple Task App）：

1. **添加任务**
   - 用户可以通过输入框输入任务内容
   - 点击添加按钮或按 Enter 键将任务添加到列表
   - 空输入不能添加任务

2. **删除任务**
   - 每个任务有删除按钮
   - 点击删除按钮可以移除该任务

3. **标记完成**
   - 用户可以点击任务切换完成状态
   - 完成的任务有视觉区别（如删除线）

---

## 4. 非功能需求

### 4.1 技术约束

说明项目的技术约束和限制。

**示例**：
- 使用 HTML、CSS、JavaScript
- 不使用前端框架（如 React、Vue）
- 不使用后端服务或数据库
- 代码清晰易读，便于多 Agent 理解

### 4.2 质量要求

**示例**：
- 代码结构清晰
- 功能正确无误
- 用户体验友好

---

## 5. 边界说明

明确项目的边界，什么在范围内，什么不在范围内。

**在范围内**：
- 核心功能实现
- 基本用户体验优化
- 代码质量保证

**不在范围内**：
- 复杂的业务逻辑
- 高级功能（如数据同步、多设备支持）
- 性能优化（除非有明确要求）

---

## 6. 不做什么

明确说明本项目**不做什么**，避免范围蔓延。

**示例**（来自 Simple Task App）：
- ❌ 不支持任务编辑
- ❌ 不支持任务优先级
- ❌ 不支持任务分类或标签
- ❌ 不支持数据持久化（除非后续阶段明确要求）
